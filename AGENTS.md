# AGENTS.md

This document orients AI agents and developers working on this codebase.

## Project Overview

A personal portfolio site for Marisol Fenn, a fictional Brooklyn-based visual designer. Built with TanStack Start (React 19 + Vite) and deployed on Netlify. The site has five pages: a home/hero page, an image gallery, a project showcase, an about page, and a contact page with social links.

### Tech stack

| Layer | Technology |
|-------|------------|
| Framework | TanStack Start |
| Frontend | React 19, TanStack Router v1 |
| Build | Vite 7 |
| Styling | Tailwind CSS 4 (custom editorial theme, no default shadcn palette) |
| Content | Content Collections (type-safe markdown for project entries) |
| Forms | Netlify Forms |
| Images | Netlify Image CDN (`/.netlify/images`) |
| Language | TypeScript 5.9 |
| Deployment | Netlify |

## Directory structure

```
├── content/projects/*.md        Project case studies (frontmatter + body), read via content-collections.ts
├── public/gallery/*.jpg         Source artwork for the gallery, generated by scripts/generate-gallery.mjs
├── public/headshot-on-white.jpg Portrait used on the home and about pages
├── public/contact.html          Static form shell so Netlify's build-time form parser detects the contact form
├── scripts/generate-gallery.mjs One-off script that generated the placeholder gallery artwork with sharp
├── src/components/site-header.tsx / site-footer.tsx   Global nav and footer, rendered from __root.tsx
├── src/components/optimized-image.tsx                 <img> wrapper that requests responsive sizes from Netlify Image CDN
├── src/lib/socials.ts           Single source of truth for social links (used in footer + contact page)
├── src/routes/__root.tsx        Root layout: fonts, header, footer
├── src/routes/index.tsx         Home page
├── src/routes/gallery.tsx       Image gallery with lightbox
├── src/routes/projects.tsx      Project showcase (reads content/projects via content-collections)
├── src/routes/about.tsx         About page
├── src/routes/contact.tsx       Contact form (Netlify Forms) + social links
├── content-collections.ts       Zod schema for the `projects` collection
└── netlify.toml                 Build command/publish dir, dev server port
```

## Conventions & non-obvious decisions

- **No shadcn/ui primitives.** The original scaffold's Radix-based `src/components/ui/*` components were removed — the design uses plain Tailwind utility classes directly against a custom palette (see "Theme" below), since the editorial aesthetic didn't map well to the default shadcn look.
- **Theme tokens** live in `src/styles.css` as CSS variables (`--paper`, `--ink`, `--clay`, `--rust`, `--moss`, `--ochre`) exposed to Tailwind via `@theme inline`. `--radius` is set to `0` for the sharp, unrounded look used throughout.
- **Fonts** are loaded via Google Fonts `<link>` tags in `__root.tsx`'s `head()`: **Fraunces** (display serif, used for all headings) and **Archivo** (body/UI sans).
- **Gallery images are real JPEGs**, not inline SVG placeholders, specifically so they can be run through Netlify Image CDN for genuine width/format optimization. They were generated once with `sharp` (see `scripts/generate-gallery.mjs`); `sharp` itself is not a project dependency — install it temporarily (`pnpm add -D sharp`) if you need to regenerate or add pieces.
- **`OptimizedImage`** (`src/components/optimized-image.tsx`) is the only way images should be rendered in page content — it builds a `srcSet` against `/.netlify/images?url=...&w=...` so the CDN resizes and format-negotiates (WebP/AVIF) per request.
- **Contact form** submits via `fetch` to `/contact.html`, matching the static hidden form in `public/contact.html` that Netlify's build-time parser needs to detect and register the form.
